Política de privacidad

Última actualización: 11 de noviembre de 2026

LatiFi nunca custodia tus llaves privadas ni tus fondos. Esto es una demostración académica en una red de pruebas, y el dinero de la app no tiene valor real.

1. Qué datos recopilamos

En este sitio web, nada sobre ti. El sitio no tiene cuentas, formularios, cookies, analítica ni scripts de seguimiento. Guarda un solo valor en el almacenamiento local de tu navegador, llamado latifi.lang. El valor es "en" o "es" y recuerda tu idioma. Se queda en tu dispositivo y el sitio nunca lo envía a ningún lado.

En la app y la API manejamos estos datos:

  • tu dirección de billetera, que es pública en la blockchain;
  • tu nombre visible, de hasta 80 caracteres, que cualquiera puede leer junto a tu dirección;
  • tu contacto, un correo electrónico o un teléfono, que solo tú puedes ver y que la app pide antes de que publiques o fondees un préstamo;
  • un desafío de inicio de sesión, un número aleatorio con sus horas de emisión y de vencimiento, que usas una sola vez para demostrar que controlas tu billetera;
  • tu reputación, que la API calcula a partir de tus pagos y de tu perfil.

Cuando usas la app, el servidor que ejecuta la API puede ver la dirección IP de tus solicitudes. Para limitar los abusos, la API cuenta las solicitudes por dirección IP y por dirección de billetera, y guarda esos conteos en memoria. El equipo no añadió a la app herramientas propias de analítica, publicidad ni seguimiento.

2. Qué datos nunca recopilamos (llaves, fondos)

LatiFi nunca custodia tu llave privada, tu frase de recuperación ni tus fondos. La app crea tu llave en tu teléfono y firma las transacciones allí. Nada que pueda mover tu dinero llega a nuestros servidores.

No hay contraseñas, porque inicias sesión firmando un mensaje con tu billetera. La app no pide a Android acceso a tu ubicación, tus contactos, tus fotos, tu cámara ni tu micrófono.

3. Cómo usamos los datos

Usamos tu nombre visible y tu reputación para que los prestamistas vean quién pide antes de fondear una solicitud. Usamos tu contacto para marcar tu perfil como completo. La API lo muestra solo a ti y nunca lo devuelve para otra dirección.

Usamos el desafío de inicio de sesión para comprobar que controlas la billetera, y luego la API entrega a tu app un token de sesión que dura 15 minutos. Usamos las direcciones IP y las direcciones de billetera solo para limitar cada cuánto alguien puede pedir un inicio de sesión.

No vendemos tus datos y no los usamos para publicidad.

4. Datos públicos de la blockchain

El contrato inteligente registra las solicitudes, los fondeos, los pagos y los incumplimientos en Polygon Amoy, una blockchain pública. Cualquiera puede leerlos. Incluyen tu dirección de billetera, los montos de los préstamos y las fechas.

Nadie puede editar ni borrar esos registros, ni tú ni el equipo. El contrato no tiene dueño ni administrador. La API copia los registros en su propia base de datos para mostrar el listado de solicitudes a los prestamistas y para calcular la reputación.

Si tu nombre visible te identifica, cualquiera puede relacionar tu dirección de billetera y tus préstamos contigo. Elige un nombre que te resulte cómodo hacer público.

5. Servicios que usamos

Estos servicios participan en el funcionamiento de LatiFi. Cada uno trata los datos según su propia política.

  • GitHub Pages aloja este sitio web. GitHub puede registrar datos de la solicitud, como tu dirección IP.
  • La API funciona en un servidor que opera el equipo del proyecto, un servidor privado virtual en Hetzner, con su base de datos en el mismo servidor.
  • Un nodo público de Polygon Amoy, PublicNode por defecto, recibe las transacciones que envía tu app y la dirección IP de la app.
  • Reown (WalletConnect) ofrece la conexión opcional con una billetera que ya tienes. Solo participa si eliges esa opción.
  • ExchangeRate-API aporta los tipos de cambio que la API muestra en monedas locales. La API le pide los tipos de cambio y no le envía datos sobre ti.

Esta página incluye un video del producto alojado en YouTube. Usamos el dominio youtube-nocookie.com, que no instala cookies de seguimiento hasta que reproduces el video. El navegador pide el video cuando te acercas a esa sección, y YouTube ve tu dirección IP en ese momento. La página no hace ninguna otra solicitud a otro sitio web. Si el video no carga, debajo tienes un enlace para verlo en YouTube.

6. Cuánto tiempo conservamos los datos

Los desafíos de inicio de sesión se borran unas 24 horas después de vencer. Los tokens de sesión vencen a los 15 minutos. Los conteos de solicitudes que se usan para limitar abusos se quedan en memoria y se descartan cuando quedan inactivos.

El equipo todavía no fijó un plazo de conservación para los perfiles (nombre visible y contacto). Se quedan en la base de datos de la API hasta que alguien los elimine. El valor del idioma se queda en tu navegador hasta que borres los datos de este sitio.

Los registros de la blockchain son permanentes.

7. Tus opciones

Puedes navegar por este sitio web sin entregar ningún dato. Puedes borrar el valor del idioma cuando quieras, borrando los datos de este sitio en tu navegador.

Puedes cambiar tu nombre visible y tu contacto en la app cuando quieras. Si prefieres privacidad, elige un nombre visible que no te identifique. Necesitas un perfil completo para publicar o fondear un préstamo.

La API todavía no tiene una operación para eliminar un perfil. Para pedir al equipo que elimine el tuyo, usa la vía de contacto de abajo e indica solo tu dirección de billetera, que ya es pública. Los registros de la blockchain no se pueden eliminar.

8. Menores de edad

LatiFi es una demostración académica para personas adultas que pueden participar en un préstamo. No está diseñada para menores de edad y el equipo no recopila sus datos de forma consciente. Si crees que un menor creó un perfil, avísanos por la vía de contacto de abajo para que el equipo lo revise.

9. Cambios

El equipo puede actualizar esta política a medida que cambie el proyecto. La versión nueva reemplaza a la anterior en esta página, y la fecha de arriba indica cuándo cambió. Si el sitio web empieza a usar analítica o cookies, esta página lo dirá antes.

10. Contacto

Para hacer una pregunta o avisar de un problema, abre una incidencia en el rastreador público de incidencias del repositorio del sitio web de LatiFi en GitHub. El proyecto todavía no tiene un correo electrónico público ni una dirección postal.

Cualquiera puede leer lo que publiques allí. No compartas una llave privada, una frase de recuperación, un correo electrónico ni un número de teléfono.
